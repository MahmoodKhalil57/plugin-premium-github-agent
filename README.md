# PremiumCMS plugin

Generated from the PremiumCMS plugin starter. Edit `src/`, bump `version` in
`package.json`, push to `main` — the workflow builds, bundles and publishes the
release to the marketplace, and every site that installed it sees an update.

- `emdash-plugin.jsonc` — manifest (id, capabilities, admin UI)
- `src/` — plugin source (`bunx emdash-plugin build`)
- `tests/` — `bunx vitest run`
